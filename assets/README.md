# Calculadora de IMC

Exercício prático desenvolvido durante meus estudos de **JavaScript básico**, com foco em lógica condicional, manipulação do DOM e tratamento de dados inseridos pelo usuário.

O projeto calcula o **IMC (Índice de Massa Corporal)** a partir do peso e da altura informados.

---

## Conceitos praticados

- Funções em JavaScript
- Captura de eventos (`submit`)
- Uso de `preventDefault`
- Operações matemáticas
- Condicionais (`if / else if`)
- Manipulação do DOM

---

## Funcionalidades

- Entrada de peso e altura
- Conversão de altura de cm para metros
- Cálculo automático do IMC
- Exibição do resultado com classificação
