# Timer em JavaScript

Exercício prático desenvolvido durante meus estudos de **JavaScript**, acompanhando a aula do professor e aplicando melhorias orientadas ao longo do processo.

O objetivo foi praticar **lógica de programação** e o uso de funções de tempo.

---

## Conceitos praticados

- Funções em JavaScript  
- `setInterval` e `clearInterval`  
- Manipulação do DOM  
- Eventos com `addEventListener`  
- Formatação de tempo (`Date`)

---

## Funcionalidades

- **Iniciar**: começa a contagem do tempo  
- **Pausar**: interrompe o timer  
- **Zerar**: redefine para `00:00:00`  

O tempo é exibido no formato `HH:MM:SS`.
