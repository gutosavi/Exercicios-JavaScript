# Verificador de Idade e Gênero

Exercício prático desenvolvido durante meus estudos de **JavaScript básico**, com foco em lógica condicional e manipulação do DOM a partir de dados informados pelo usuário.

O projeto calcula a idade com base no ano de nascimento e exibe uma imagem correspondente ao gênero e à faixa etária.

---

## Conceitos praticados

- Funções em JavaScript
- Condicionais (`if / else`)
- Operadores lógicos
- Manipulação do DOM
- Uso de `Date` para obter o ano atual
- Alteração dinâmica de imagens

---

## Funcionalidades

- Entrada do ano de nascimento
- Seleção de gênero
- Cálculo automático da idade
- Exibição de mensagem com idade e gênero
- Exibição de imagem conforme faixa etária
